# OTAKUVERSE V2 — Single Player

A fresh, dependency-free single-player anime social-network life simulator.

## Run locally

No npm, Node.js, database, or terminal setup is required.

1. Download this folder from GitHub.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Start playing.

The game saves player progress automatically in browser localStorage.

## Included

- 30 original fictional AI anime characters
- Player onboarding/profile
- Social feed
- Post creation
- Virality and follower growth
- Trending page
- Character discovery
- Direct messages with character-specific responses
- Notifications
- Leaderboard
- Profile progression
- AI-character world activity simulation
- Responsive desktop/tablet/mobile UI
- Dark neon anime glassmorphism design

## Current scope

This V2 is intentionally single-player and self-contained so it can be opened directly without the Node/SQLite setup that caused issues in the first build. The AI/API backend can be added as a later version without exposing API keys in the browser.
